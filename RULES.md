# 🏆 VAVA BOT4BOTS CUP — Valorant Championship Rules

---

## 1. TOURNAMENT OVERVIEW

**Vava Bot4Bots Cup** is a community Valorant tournament for this Discord server. Teams compete in a single-elimination bracket with a Best-of-3 (Bo3) format for all rounds.

| Detail | Value |
|--------|-------|
| Game | Valorant |
| Mode | Custom Game, Standard |
| Format | Single Elimination |
| Match Type | Best-of-3 (Bo3) |
| Team Size | 5 players + up to 2 substitutes |
| Server Region | Europe (configurable) |
| Map Pool | Competitive rotation |

---

## 2. PLAYER ELIGIBILITY

- Must be a member of this Discord server
- Must have a valid Riot ID (Name#Tag)
- Any rank is welcome — teams are balanced algorithmically
- Players must be available during scheduled match windows
- Smurfs and banned accounts are prohibited — DQ on evidence

---

## 3. TEAM FORMATION

Teams are assembled by the tournament organizer using a **balanced draft algorithm** based on player ranks:

1. Players are sorted by their numeric rank (Iron 1 = 1 → Radiant = 25)
2. Teams are filled using a **snake draft** to ensure fair distribution
3. Every team gets a roughly equal average rank
4. Role preferences are considered but not guaranteed
5. Captains are assigned to the highest-ranked player on each team

Players may request team swaps before the tournament starts — all swaps must be approved by the organizer.

### 3.1 Substitutes

- Each team may register up to 2 substitute players
- Substitutes must also be registered via the form
- A substitute may not have a higher rank than the player they replace
- Substitutions must be announced before the match starts

---

## 4. MAP SELECTION

### 4.1 Map Pool

Only maps in the **current competitive rotation** are eligible. The default pool:

> Ascent, Bind, Haven, Split, Lotus, Pearl, Fracture, Abyss, Sunset

### 4.2 Map Veto (Bo3)

Teams alternate bans using the following procedure (A = higher seed):

| Stage | Action | By |
|-------|--------|-----|
| 1 | Ban 1 map | Team A |
| 2 | Ban 1 map | Team B |
| 3 | **Pick Map 1** | Team A |
| 4 | **Pick Map 2** | Team B |
| 5 | Ban 1 map | Team A |
| 6 | Ban 1 map | Team B |
| 7 | **Decider Map 3** | Remaining |

Team A picks which side (Attack/Defense) to start on Maps 1 and 3.
Team B picks which side to start on Map 2.

Map picks must be locked **30 minutes before match time**.

## 5. MATCH RULES

### 5.1 Lobby Settings

| Setting | Value |
|---------|-------|
| Mode | Standard |
| Cheats | OFF |
| Overtime | ON (Competitive rules) |
| Tournament Mode | ON |

### 5.2 Win Condition

- First team to win **13 rounds** wins the map
- If tied 12-12, overtime begins
- First team to win **2 maps** wins the match (Bo3)

### 5.3 Agent Select

- No agent bans
- All agents are available
- Teams may run any composition

### 5.4 Technical Pauses

- Each team is allowed **2 technical pauses** per map
- Each pause: max **5 minutes**
- Tactical pauses: **1 per team per half** (standard competitive)

---

## 6. SCHEDULING

Matches are scheduled by the tournament organizer. The default cadence:

| Round | Window |
|-------|--------|
| Quarterfinals | Weekend 1 (Sat–Sun) |
| Semifinals | Weekend 2 (Sat) |
| Grand Final + 3rd Place | Weekend 2 (Sun) |

Teams must confirm their match time **48 hours before** the scheduled slot. If a team cannot make the default time, they must coordinate with their opponent to find an alternative within the same weekend window. If no agreement is reached, the organizer sets the time unilaterally.

---

## 7. MATCH REPORTING

After each match:
1. **The winning team captain** reports the result using `/cup_report <match_id> <our_score> <their_score>`
2. Both captains must confirm the result
3. A screenshot of the final scoreboard is recommended (not required)
